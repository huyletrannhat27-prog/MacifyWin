# Tài nguyên mã nguồn mở cho MacifyWin

MacifyWin **không** phân phối bất kỳ tài nguyên độc quyền nào của Apple (font San Francisco, con trỏ macOS gốc, icon hay hình nền Apple).

## Danh sách thư mục con

1. `fonts/inter/`
   - Đặt các file `.ttf` / `.otf` của bộ font **Inter** (giấy phép SIL Open Font License 1.1) tại đây.
   - Tải chính thức tại: https://rsms.me/inter/ hoặc Google Fonts.
2. `cursors/capitaine/`
   - Đặt bộ con trỏ **Capitaine Cursors** (giấy phép LGPL-3.0) đã chuyển sang định dạng `.cur` / `.ani` tại đây (`default.cur`, `pointer.cur`, `text.cur`, `wait.ani`, `progress.ani`, `ns-resize.cur`, `ew-resize.cur`, `nwse-resize.cur`, `nesw-resize.cur`, `all-scroll.cur`, `not-allowed.cur`).
   - Nguồn gốc: https://github.com/keeferrourke/capitaine-cursors
3. `wallpapers/`
   - Đặt ảnh nền `macify-gradient.png` (tự tạo / CC0) tại đây để script tự động áp dụng khi cài đặt.
