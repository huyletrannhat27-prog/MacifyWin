# Tương thích phiên bản Windows

| Phiên bản Windows | Build | Hỗ trợ | Ghi chú chi tiết |
| :--- | :--- | :--- | :--- |
| **Windows 11 (22H2 / 23H2 / 24H2)** | `>= 22621` | **Đầy đủ (Khuyên dùng)** | Hỗ trợ đầy đủ bo góc DWM, Mica/Acrylic qua `MicaForEveryone`, mod Windhawk mới nhất, `Seelen UI` và `Files App`. |
| **Windows 11 (21H2)** | `22000` | **Tốt** | Hầu hết tính năng hoạt động; nên cập nhật lên 22H2+ để `Files App` và `Windhawk` ổn định nhất. |
| **Windows 10 (21H2 / 22H2)** | `19044 - 19045` | **Hỗ trợ một phần** | `Seelen UI`, `Files App`, `MacType`, `AutoHotkey`, `Capitaine Cursors`, `VS Code` chạy tốt. **Không có** bo góc DWM và Mica gốc (script tự bỏ qua `MicaForEveryone`). |
| **Windows 10 cũ hơn / Windows 8.1** | `< 19044` | **Không hỗ trợ** | `winget` và các app hiện đại yêu cầu Windows 10 1809+ trở lên. |
