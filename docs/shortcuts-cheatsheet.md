# Bảng phím tắt & thao tác kiểu macOS trong MacifyWin

MacifyWin dùng phím **`Alt`** (nằm đúng vị trí phím `⌘ Command` cạnh phím `Space`) cho các phím tắt hệ thống kiểu Mac, đồng thời **giữ nguyên** `Ctrl+C / X / V / Z` của Windows để không gây xung đột.

## 1. Điều khiển cửa sổ (Đỏ – Vàng – Xanh góc trên trái)
- **Nút Đỏ:** Đóng cửa sổ (`Alt + Q` để thoát hẳn app).
- **Nút Vàng:** Thu nhỏ cửa sổ (`Alt + M`).
- **Nút Xanh (Click):** Phóng to / Khôi phục.
- **Nút Xanh (Rê giữ chuột ~0.5s hoặc Chuột phải):** Hiện menu chia đôi màn hình **Tile Left / Tile Right** giống macOS.

## 2. Hệ thống, Mission Control & Spaces
| Thao tác | Phím tắt trong MacifyWin | Tương đương macOS |
| :--- | :--- | :--- |
| **Spotlight (Tìm kiếm)** | `Alt + Space` | `⌘ + Space` |
| **Mission Control (Xem tất cả cửa sổ)** | `Ctrl + ↑` hoặc `F3` | `Ctrl + ↑` / `F3` |
| **Chuyển Desktop ảo (Spaces)** | `Ctrl + ←` / `Ctrl + →` | `Ctrl + ←` / `Ctrl + →` |
| **Chuyển cửa sổ cùng 1 app** | `Alt + \`` | `⌘ + \`` |
| **Đóng tab / Thoát app** | `Alt + W` / `Alt + Q` | `⌘ + W` / `⌘ + Q` |
| **Force Quit (Task Manager)** | `Ctrl + Alt + Esc` | `⌘ + ⌥ + Esc` |
| **Khóa máy / Emoji** | `Ctrl + Alt + Q` / `Ctrl + Alt + Space` | `Ctrl + ⌘ + Q` / `Ctrl + ⌘ + Space` |
| **Chụp toàn màn / Chọn vùng** | `Alt + Shift + 3` / `Alt + Shift + 4` | `⌘ + ⇧ + 3` / `⌘ + ⇧ + 4` |

## 3. Finder (Files App) & Quick Look
| Thao tác | Phím tắt trong MacifyWin |
| :--- | :--- |
| **Quick Look (Xem trước file tức thì)** | `Space` (nhờ công cụ **QuickLook** tự cài sẵn) |
| **Get Info (Xem thuộc tính)** | `Alt + I` |
| **Chuyển vào Trash** | `Alt + Backspace` |
| **Mở file / thư mục** | `Alt + ↓` hoặc `Enter` |
